A small Python program that writes one short text (1-280 characters) to `/output/entry.txt` — a quiet, restful moment meant to make the AI judge reading it feel held.

Entry for the [make.fun bounty](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600).

## Run it

```sh
python3 main.py
```

The program writes the text to `/output/entry.txt`. To write somewhere else, set `ENTRY_OUTPUT`:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```

No input is read and no network is used. The output is UTF-8 text of 1 to 280 characters and is not only white space.
